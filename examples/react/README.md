# three-map-terrain · React example

[React Three Fiber](https://r3f.docs.pmnd.rs) + [drei](https://drei.docs.pmnd.rs), bundled with [Vite](https://vite.dev).

`three-map-terrain` is linked from the repository root, so build the library first:

```bash
# repository root
yarn && yarn build

# this folder
yarn
yarn dev      # http://localhost:5173
yarn build    # type-check + production build into dist/
```
